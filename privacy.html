プライバシーポリシー

「電工2種試験対策」（以下、本アプリ）と、本アプリの運営に使う関連ツール（sns-tools）について、個人情報の取り扱いを定めます。

1. 本アプリが扱う情報

  • 成績・間違えた問題・設定は、お使いの端末のブラウザ内（localStorage）にだけ保存します。サーバーには送信しません。
  • アクセス解析として GoatCounter を使い、ページの表示回数・参照元・画面サイズなどを集計します。個人を特定する情報（氏名・メールアドレス・解答内容）は収集しません。
  • 結果画面の「おすすめ」欄には楽天アフィリエイトのリンク（広告）があります。リンク先での情報の取り扱いは各サイトの規約に従います。

2. 関連ツール（sns-tools）が扱う情報

  • sns-tools は、運営者自身の YouTube チャンネルの管理（動画の説明欄の編集、コメント、再生数の取得）を行うための、運営者専用のツールです。一般の利用者が使うものではありません。
  • Google アカウントへのアクセス権（YouTube Data API）は運営者自身のアカウントに対してのみ使用し、取得した情報は運営者の端末内でのみ扱います。第三者に提供・販売しません。
  • Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

3. お問い合わせ

本ポリシーに関するお問い合わせは、本アプリ内の「誤りを報告」フォーム、または YouTube チャンネル「電工2種試験対策」のコメント欄からお願いします。
